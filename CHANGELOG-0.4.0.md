# Ollie TV 0.4.0

- Built a 24-hour proportional EPG timeline with day navigation and programme details.
- Added immediate clear MPEG-TS HLS recording and direct HTTP recording.
- Added persistent WorkManager scheduled recordings with duration, network constraints, cancellation and recording-library management.
- Added playlist enable/disable, rename, reorder, refresh, delete, per-source refresh interval and XMLTV URL configuration.
- Added hourly WorkManager automatic source/EPG refresh.
- Preserved favourites when refreshing a playlist.
- Replaced basic playback controls with a custom auto-hiding HUD.
- Added DPAD channel zapping, 10-second seeking, play/pause key support, aspect ratio modes, audio-language cycling and subtitle toggle.
- Added Room database migration 1 → 2.
